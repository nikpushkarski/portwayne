# Project assistant defaults

## Game development: learn while building

For any request about programming this game—including orders to implement features, debugging, game math, engine APIs, networking, UI code, asset-generation tooling, tests, or builds—read and follow `.agents/skills/gamedev-n-learn/SKILL.md` and its `preferences.md` before responding or changing gameplay source.

The default is guided education: concise, actionable hints first; diagrams when the user struggles; progressively stronger scaffolding. Explicit requests for direct answers or direct implementation override the guided approach for that task. Never turn unrelated requests, artwork-only work, or skill tuning into compulsory lessons.

Also load the skill when the user asks to show, tune, or reset **gamedev_n_learn** preferences. Its Pi-compatible command name is **gamedev-n-learn**.

This instruction makes the teaching workflow the project default rather than relying solely on automatic skill selection. It is a model instruction, not a hard technical enforcement mechanism, and does not override higher-priority instructions.
