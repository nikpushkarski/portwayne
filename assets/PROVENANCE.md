# Asset provenance

All game SVG artwork and WAV audio in this folder were procedurally authored for this project by the coding assistant. The visual direction follows the project's earlier Forklift Certified mock screenshot. These files were not downloaded from an asset marketplace, traced from an external image, or sampled from third-party recordings.

`generate.py` contains the editable source for every generated runtime asset. It uses Python's standard library only. Sound effects use mathematical oscillators and seeded noise. SVGs use geometric shapes and paths; runtime images do not embed third-party fonts. The contact sheet uses the browser's generic sans-serif font for reference labels only.

No third-party asset attribution requirements have been identified for the generated files. This is a provenance statement, not a guarantee of copyright protection, trademark availability, exclusivity, or legal clearance. Review applicable platform policies for AI-assisted/generated content when publishing and make any required disclosures accurately.

Assets added later from other sources must have their own provenance and license notices recorded separately.
